Adult Census Dataset – Machine Learning Project

About
- This project uses machine learning to predict a person's income group based on census data.

Tools Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook Adult Census Dataset – Machine Learning Project

Dataset

- Adult Census Dataset (Excel)

Target Column: income

- <=50K
- >50K

Project Steps

- Load the dataset.
- Clean and preprocess the data.
- Handle missing values and duplicates.
- Visualize the data.
- Split the dataset.
- Perform feature selection.
- Train classification models.
- Evaluate model performance.

Algorithms Used

- Logistic Regression
- Decision Tree
- Random Forest

Evaluation Metrics

- Accuracy, Precision, Recall, and F1-score.

Conclusion

- This project demonstrates the use of machine learning algorithms to predict income categories using census data.
